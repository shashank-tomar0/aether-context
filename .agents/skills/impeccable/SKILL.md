# Impeccable Skill

## Directives
1. **Motion & Transitions**:
   - Every interactive element has smooth, physics-based or calibrated transitions (ease-out 150ms-250ms).
   - Enter/exit animations for modals, dropdowns, and notifications using Framer Motion or lightweight CSS keyframes.
   - Staggered reveals for lists, charts, and graph nodes.
2. **Tactile Micro-Interactions**:
   - Hover states must feel alive: subtle border brightening, subtle scale (1.01-1.02), or backdrop-filter diffusion.
   - Active click feedback (active scale 0.98, tactile press).
   - Copy-to-clipboard, action buttons, and status chips with instant optimistic feedback and toast confirmation.
3. **Data Polish & Realism**:
   - Live stream indicators (pulsing beacon dot, dynamic time delta e.g., '12ms ago').
   - Interactive data visualizations with tooltip scrubbers, zoom/pan controls, and active node inspector panels.
4. **Zero Layout Shifts**:
   - Strict container dimensions, aspect ratios, and skeleton placeholders prevent layout snapping during async data fetches.
