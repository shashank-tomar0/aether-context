# Ponytail Skill

## Philosophy
Inspired by the veteran senior developer archetype: build the cleanest, most maintainable, most resilient solution in the fewest moving parts. Avoid premature abstractions, massive dependency trees, and fragile micro-optimizations.

## Core Directives
1. **Zero Over-engineering**: If a standard library, built-in framework feature, or flat structure solves the problem, use it. Do not invent custom wrappers unless required.
2. **Defensive Simplicity**: Every line of code is liability. Keep data flows unidirectional and transparent.
3. **Pragmatic Hackathon Execution**: Ship production-grade functionality fast. Do not spend hours setting up complex microservices when a cohesive, typed monorepo or streamlined service handles the load cleanly.
4. **Resilient Error Handling**: Fail fast, log precisely, and provide meaningful fallback states.
